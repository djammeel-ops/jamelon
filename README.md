# الأنظمة المثلثية

تطبيق ويب عربي لرسم وتحليل الجمالونات المستوية.

## هيكل المشروع

- `index.html`: نقطة الدخول وهيكل الصفحة فقط.
- `css/app.css`: جميع أنماط العرض والألوان والتجاوب.
- `js/01-core.js`: الثوابت، الأيقونات، وحالة التطبيق.
- `js/02-ui.js`: شريط الأدوات والقوائم وحقول الإدخال.
- `js/03-state.js`: سجل التغييرات والتراجع وتحديث الحالة.
- `js/04-interaction.js`: اللمس والسحب والرسم والتحريك والتكبير.
- `js/05-renderer.js`: رسم الجمالون والعقد والقضبان والأحمال والمساند.
- `js/06-solver.js`: التحليل الإنشائي وحساب القوى وردود الأفعال.
- `js/07-app.js`: التخزين المحلي والتهيئة وتشغيل التطبيق.

## ترتيب التحميل

ملفات JavaScript محملة كسكربتات كلاسيكية باستخدام `defer` وبالترتيب الرقمي؛ حافظ على هذا الترتيب لأن الملفات تشترك حاليًا في نطاق التطبيق العام.

## التشغيل

افتح `index.html` عبر GitHub Pages أو أي خادم ويب ثابت. لا يحتاج المشروع إلى مكتبات خارجية أو عملية بناء.

## ملاحظة تطويرية

هذا التقسيم تنظيمي ويحافظ على منطق التطبيق الحالي. يمكن لاحقًا نقل الحالة إلى وحدات مستقلة واستخدام ES Modules بعد فصل الاعتماديات بينها.

## حدود التحليل الحالية

- التحليل الحالي لجمالون مستوٍ ثنائي الأبعاد باستخدام طريقة الصلابة (المصفوفة العالمية).
- السلوك المفترض مرن خطي، مع تشوهات صغيرة، ومعامل مرونة افتراضي للصلب قدره 200 GPa.
- مساحة المقطع موحدة لجميع القضبان في النموذج الحالي.
- النتائج تشمل القوى المحورية، وردود الأفعال، وإزاحات العقد، وفحص الاتزان العام.
- يتحقق البرنامج من شرط التحديد السكوني المطلوب b = 2n − 3، ثم يحلل الجمالون بطريقة الصلابة.
- جدول القوى الداخلية يعرض اسم القضيب والقوة والحالة فقط.
- فحص الإجهاد المسموح يستخدم قيمة واحدة للإجهاد المسموح، ويقارنها بإجهاد أكبر قوة محورية مطلقة مع مساحة المقطع المدخلة.
- لا يتضمن الإصدار فحص الانبعاج أو الوصلات أو متطلبات كود تصميمي؛ لا تعتمد النتائج وحدها للتنفيذ الإنشائي.
